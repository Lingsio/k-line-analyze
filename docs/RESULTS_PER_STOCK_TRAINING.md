# Per-Stock Training Experiment

> **实验状态**: ✅ Pilot测试已完成 (2026-02-07)
> **结论**: ❌ Per-Stock方法表现不如混合训练，主要原因是单股数据量不足导致严重过拟合
> **建议**: 不推荐继续扩展，应考虑迁移学习或分组训练方案

---

## 实验动机

现有混合训练方式（107只股票混合）的准确率约**50-51%**，接近随机猜测。可能的原因：
- 不同股票的波动模式差异大（行业、市值、流动性不同）
- 混合训练导致模型学到"平均模式"，无法捕捉个股特征
- 支撑位/阻力位等技术指标因股票而异

## 实验假设

**假设：每只股票单独训练专用模型，可以更好地学习该股票的独特模式，提高预测准确率**

**实验结论**: ❌ **假设被否定**。单股数据量不足（约2400样本）导致严重过拟合，平均性能（F1=45.67%）显著低于混合训练（F1=50.65%）。

## 方案对比

| 维度 | 混合训练（现有） | Per-Stock训练（新方案） |
|------|------------------|------------------------|
| **训练方式** | 107只股票混合 → 1个模型 | 每只股票 → 1个独立模型 |
| **Window Size** | 20天 | 60天（更长的时间窗口） |
| **训练样本数** | 69,669（混合） | 约3,814/股票 |
| **优势** | 数据量大，泛化能力强 | 个性化模式，针对性强 |
| **劣势** | 不同股票互相干扰 | 单股数据少，易过拟合 |
| **预计准确率** | 51% | 待验证（期望>55%） |
| **训练时间** | 22分钟（3次运行） | 10-15小时（100股×3次） |

## 关键配置差异

### [run_per_stock_experiments.py](../scripts/run_per_stock_experiments.py) 的特殊设计

```python
CONFIG = {
    'window_size': 60,           # 更长窗口（20→60）
    'batch_size': 32,            # 更小batch（128→32）
    'lr': 2e-4,                  # 更小学习率（4e-4→2e-4）
    'weight_decay': 1e-4,        # 更强正则化（1e-5→1e-4）
    'patience': 3,               # 更激进早停（5→3）
    'epochs': 15,                # 更少epoch（20→15）
    'num_runs': 1,               # 先跑1次（可改为3）
}
```

**设计原则：**
1. **防止过拟合**：单股数据少，使用小学习率+强正则化+早停
2. **自适应batch size**：如果股票数据<200样本，自动减小batch
3. **数据过滤**：自动跳过数据不足的股票（<100天）

## 💡 实验结论与建议

### ❌ 主要结论

1. **Per-Stock方法在当前数据量下不可行**
   - 平均F1 Score降低**10%** (0.4567 vs 0.5065)
   - 所有股票都出现严重过拟合
   - 个股差异大，整体表现不稳定

2. **不建议继续扩展到50只或100只股票**
   - Pilot结果已经明确：数据量是瓶颈
   - 扩展只会浪费计算资源（预计10-15小时）
   - 不太可能改变结论

### ✅ 推荐的改进方向

#### 方案1：**迁移学习** (推荐优先级: ⭐⭐⭐⭐⭐)

```
Step 1: 在全部107只股票上预训练 (现有模型)
Step 2: 每只股票单独微调最后1-2层 (少量参数)
优势: 结合混合训练的泛化能力 + 单独训练的个性化
预期提升: 1-3%
```

#### 方案2：**分组训练** (推荐优先级: ⭐⭐⭐⭐)

```
按行业/市场分10-15组：
- 美股科技股 → 1个模型 (约10只)
- 美股金融股 → 1个模型 (约10只)
- A股周期股 → 1个模型
- ...
优势: 平衡数据量(~7000样本/组)和个性化
预期提升: 2-5%
```

#### 方案3：**扩充数据量** (推荐优先级: ⭐⭐⭐)

```
当前: 60天窗口 → 约2400样本/股票
改进:
- 使用更长历史数据 (5年 → 10年)
- 减小窗口滑动步长 (目前1天 → 改为半天)
- 使用多尺度窗口 (20天 + 40天 + 60天)
预期: 样本数增加3-5倍
```

#### 方案4：**集成方法** (推荐优先级: ⭐⭐⭐)

```
对每只股票：
- 混合模型预测: pred_mixed (f1=0.51)
- 个股模型预测: pred_single (f1=0.46, 某些股票0.52)
- 自适应集成:
  - 如果个股模型在验证集 f1 > 0.52, 权重0.7
  - 否则使用混合模型, 权重1.0
预期提升: 1-2%
```
